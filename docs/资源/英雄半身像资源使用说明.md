# 英雄半身像资源使用说明

## 资源位置

- 半身像目录：`E:\work\dajunshi\new\client\dajunshi\Assets\Arts\04_UI\04_Hero`
- 主英雄表：`E:\work\dajunshi\new\resource\数据表\hero_英雄.xlsx`
- 多语言表：`E:\work\dajunshi\new\resource\数据表\lang_多语言.xlsx`

## 已验证事实

- 半身像目录存在 `.png` 资源和 Unity `.meta` 文件。
- 样例图片尺寸为 `1300x1080`。
- `hero_英雄.xlsx` 主表包含 `id / name / halfBody` 字段。
- `lang_多语言.xlsx` 包含 `key / CN` 字段，可把 `hero_name_1001` 映射为中文名。
- 资源映射必须以 `halfBody` 字段为准，不能硬切英雄 ID 的数字后缀。
- 当前已从来源项目导入 212 张唯一 `halfBody` PNG 到 `res://assets/content_alpha/hero_portraits`。
- 当前已生成 `data/content_alpha/reusable_hero_portrait_pool.json`，作为本项目 Content Alpha 默认可复用半身像池。

## 使用规则

- 这些资源来自项目负责人另一个自有项目，可以作为候选 UI 资源接入。
- 当前只复用半身像视觉资源；源项目技能、传记、君略、官职、势力和数值不进入本项目数据。
- 最终武将库可以只从有可复用半身像的约 200 名武将中选择，不要求补齐没有半身像的角色。
- 后续进入正式 UI 前仍需保留来源项目、字段映射和导入流程记录，避免错绑资源。
- 缺失图片、缺失文本、重复 ID、空 `halfBody` 都必须报错或记录为阻断问题。
- 不允许静默替换为默认头像来掩盖资源缺失。

## 校验方式

运行：

```powershell
py -3.14 tools\audit_hero_portrait_assets.py
```

导出 Godot 可读索引：

```powershell
py -3.14 tools\audit_hero_portrait_assets.py --export-json data\content_alpha\hero_portrait_index.json
```

导入项目内 PNG 并生成导入清单：

```powershell
py -3.14 tools\import_hero_portrait_assets.py
```

生成可复用半身像池：

```powershell
py -3.14 tools\export_reusable_hero_portrait_pool.py
```

校验 Content Alpha 打包一致性：

```powershell
py -3.14 tools\validate_content_alpha_package.py
```

通过标准：

- 主英雄表记录数可读取。
- `name` 文本 key 全部能在多语言表找到中文名。
- `halfBody` 全部能在半身像目录找到对应 `.png`。
- 导出的索引必须继续以 `halfBody` 为权威映射来源，不允许后续 UI 用英雄 ID 反推图片名。
- 可复用半身像池必须包含 212 张项目内导入 PNG。
- 可复用半身像池不得包含源项目技能、传记、君略、官职、势力或数值字段。
