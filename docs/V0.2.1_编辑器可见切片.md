# Prototype V0.2.1 编辑器可见切片

## 目标

- 打开 `scenes/main.tscn` 时能看到测试数据驱动的 3D 战略地图预览。
- 运行主场景时能看到城池、路线、行军部队和调试面板。
- 可见内容必须来自真实数据加载和真实模拟系统，不使用假状态绕过业务逻辑。

## 范围

- 新增 `StrategicMapView`，负责把运行时状态渲染为 3D 城池、路线、部队标记。
- `main.gd` 使用 `CoreDataLoader`、`CoreStateFactory`、`SortieSystem`、`MarchSystem` 构造一段可视化测试局面。
- `DebugPanel` 挂入主场景，用于同步显示同一份运行时状态。

## 边界

- 当前只使用 `data/prototype_v0_1/core_test_data.json` 的少量测试数据。
- 当前城池坐标是 V0.2.1 原型坐标，完整地图坐标仍需来自后续正式地图/数据表专项。
- 当前不是正式 UI，不代表 Beta/正式版界面质量。

## 什么时候能看到效果

- Prototype V0.2.1 起：可以在 Godot 编辑器打开主场景看到地图预览，运行项目看到动态行军切片。
- Content Alpha 起：应开始看到更接近游戏信息架构的 UI 原型。
- Beta 起：必须达到正式游戏观感，不再依赖调试面板完成主要玩法。
