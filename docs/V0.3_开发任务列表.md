# Prototype V0.3 开发任务列表

## 执行规则

- V0.3 必须建立在 V0.2/V0.2.1 已通过的统一运行时状态之上。
- 三国特色规则必须作为真实策略压力进入状态、日志、存档、AI 或 UI 调试入口，不得只显示数值。
- 文档未明确的复杂规则必须写入缺口，不用临时默认值伪装正式设计。
- 每个任务完成后必须更新本文档、运行验证、中文提交并推送。

## 需求来源

- 企划案：`06_君主_势力与汉室正统`、`08_内政与治世系统`、`11_外交_谋略与人物关系`、`13_野战_攻城_关隘与水战`。
- 完整开发需求文档：`DEV_汉室正统_官爵_称帝需求说明`、`DEV_士族_豪强_民心事件需求说明`、`DEV_人物关系_降将_忠诚需求说明`、`DEV_关隘_港口_水路战需求说明`。
- 数据母表：`master_force.legitimacy_base`、`master_force.prestige_base`、`officer_relation`、`city_governance.gentry_support`、`battle_rules.battle_type=pass/port/river`。
- 需求索引：M3 `三国特色挂载`，要求汉室、士族、关系、关隘水路作为规则层生效。
