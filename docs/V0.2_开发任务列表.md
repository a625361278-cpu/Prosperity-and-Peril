# Prototype V0.2 开发任务列表

## 执行规则

- V0.2 必须建立在 V0.1 核心闭环全部通过的基础上。
- 系统深化只能挂载到统一运行时状态，不得绕过核心状态。
- 未在四份交付文档中定义清楚的规则必须记录为缺口，不做成正式业务规则。
- 每个任务完成后必须更新本文档、运行验证、中文提交并推送。
