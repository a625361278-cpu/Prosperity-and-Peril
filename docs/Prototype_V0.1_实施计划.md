# Prototype V0.1 实施计划

## 目标

Prototype V0.1 只验证核心闭环，不验证完整游戏体验，也不伪装成正式内容版。

核心链路：

城市 -> 任命 -> 出阵 -> 行军 -> 粮草 -> 接敌 -> 战斗 -> 占领 -> 战后整合 -> 存档读档

## 来源约束

本计划必须追溯到以下来源：

- `完整策划开发需求文档`：第五篇“技术原型范围”和“核心闭环技术原型验收用例”。
- `理论企划案`：第 18 章“MVP 范围与开发验收”。
- `数据母表 V0.3`：表目录、字段字典、状态机、公式和效果样例。
- `完整需求索引与验收矩阵`：里程碑 M0/M1 和完成度边界。

## 工程结构

建议在 Godot 项目中按以下责任拆分：

- `data/`：四份文档衍生出的测试数据和导表产物。
- `scripts/data/`：数据读取、字段校验、枚举校验、外键校验。
- `scripts/simulation/`：时间、城市、势力、武将、路线、部队、战斗、战后整合。
- `scripts/save/`：存档读档，只保存局内动态状态。
- `scripts/ui/`：调试 UI 和后续正式 UI 的数据适配层。
- `scripts/map3d/`：3D 战略地图表现，不承载核心规则。
- `scenes/`：主场景、地图场景、UI 场景。
- `tools/`：资源和数据校验脚本。
- `docs/`：项目说明、路线、验收记录、缺口清单。

## 任务拆分

### Task 1：建立 Godot 工程骨架

交付：

- `project.godot`
- `scenes/main.tscn`
- 基础目录结构。

验收：

- Godot 4.6.2 可以打开工程。
- 主场景可以无错误启动。

### Task 2：建立数据导入和校验层

交付：

- 测试城市、势力、武将、路线、公式、枚举的导入结构。
- 主键、必填字段、枚举、外键校验。

验收：

- 缺字段、重复 ID、非法外键必须报错。
- 不允许用默认值掩盖缺失关键数据。

### Task 3：建立核心状态模型

交付：

- 城市状态：归属、兵力、粮草、民心、治安、新占状态。
- 势力状态：势力 ID、君主、首府、资源概览。
- 武将状态：武将 ID、可用性、任命关系。
- 路线状态：起点、终点、距离、地形修正、触发类型。
- 部队状态：出阵城、主将、兵力、粮草、路线进度、当前状态。

验收：

- 所有运行时状态能从测试数据初始化。
- 状态引用必须能追溯到数据表 ID。

### Task 4：实现时间推进

交付：

- 日推进。
- 月推进占位。
- 任务进度推进。

验收：

- 行军按日推进。
- 月结不影响 V0.1 P0 核心链路。

### Task 5：实现任命和出阵

交付：

- 任命主将或太守。
- 出阵时扣除城市兵力和粮草。
- 生成部队对象并绑定出阵城。

验收：

- 出阵不扣兵或不扣粮是硬性失败。
- 部队没有 `origin_city_id` 或粮草字段是硬性失败。

### Task 6：实现行军和粮草

交付：

- 按路线距离、速度、地形修正计算行军天数。
- 每日消耗粮草。
- 粮草不足进入缺粮状态。

验收：

- 部队不能瞬移。
- 粮草为 0 后必须产生速度、士气或战斗力惩罚。

### Task 7：实现自动战斗和占领回流

交付：

- 接敌触发。
- 自动战斗结算。
- 攻城和占领结果回流城市、部队和势力状态。

验收：

- 战斗必须产生胜负、损兵、士气变化。
- 战斗结果不回流大地图是硬性失败。

### Task 8：实现战后整合

交付：

- 占领后城市进入新占或整合状态。
- 民心、治安或收益下降。
- 整合任务能推进恢复。

验收：

- 占领后城市立即满收益是硬性失败。
- 新占状态必须可见、可存档。

### Task 9：实现调试 UI

交付：

- 当前日期。
- 城市 ID、归属、兵力、粮草、民心、治安。
- 部队 ID、出阵城、路线进度、兵力、粮草、状态。
- 路线 ID、距离、预计天数。
- 战斗结果和战后恢复进度。
- 错误和状态流转日志。

验收：

- UI 显示必须来自真实状态，不允许静态假展示。

### Task 10：实现存档读档

交付：

- 保存城市、部队、路线进度、粮草、状态机和当前日期。
- 读取后恢复核心闭环中途状态。

验收：

- 城市、部队或势力状态无法存档是硬性失败。
- 静态主数据不复制进存档，只保存引用和动态状态。

## QA_CORE P0 验收

Prototype V0.1 必须通过：

- 数据导入成功。
- A 城状态可查看。
- 测试武将可任命。
- 出阵生成部队。
- 出阵扣除城市兵力。
- 部队携带粮草。
- 行军推进但不瞬移。
- 行军完成进入接敌状态。
- 行军每日消耗粮草。
- 缺粮进入惩罚状态。
- 接敌触发。
- 野战自动结算。
- 攻城触发。
- 占领结果改变城市归属。
- 战后整合状态生效。

P1 的恢复任务、非法状态跳转和存档读档应尽量纳入 V0.1，若未完成必须明确写入已知问题，不得视为正式闭环完成。

## V0.1 不做内容

- 不做完整大地图。
- 不做完整武将库。
- 不做完整技能库。
- 不做完整历史事件。
- 不做完整外交 AI。
- 不做完整都督府 AI。
- 不做完整水战模式。
- 不做复杂合战 UI。
