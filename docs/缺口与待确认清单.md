# 缺口与待确认清单

## 内容库缺口

- 完整城池库仍是后续专项。
- 完整武将库仍是后续专项；当前 Content Alpha 已允许从 212 张可复用半身像中筛选最终武将，不要求覆盖没有半身像的全部历史人物。
- 完整技能/战法库仍是后续专项。
- 剧本初始状态仍是后续专项。
- 历史事件链仍是后续专项。

## UI 与资源缺口

- 半身像资源来自项目负责人另一个自有三国项目，不需要额外授权流程；项目内导入、资源命名映射、打包烟测、候选名册、独立浏览组件和 Content Alpha 资源工作台已完成，后续缺口是正式武将 UI 如何选用这 212 张可复用半身像。
- UI 信息架构规格、线框规格、主题 Token、基础 Godot Theme 资源、正式主界面 HUD 外壳、城市详情面板、任命出阵面板、战报面板、事件日志面板、存档读档面板和 Playable Slice 推进一日链路已完成并进入测试；正式 UI 视觉风格方向图已确认，授权中文 UI 字体、正式武将选择器、路线预览、完整历史事件链、多槽存档 UI 和存档版本迁移仍需后续专项完成。
- 当前阶段允许低优先级系统只保留正式入口和阻塞说明；下一步应优先改善第一屏观感、地图可读性、操作反馈和完整演示节奏。
- Beta 前必须把主要玩法从调试 UI 迁移到正式 UI。

## 技术缺口

- 数据母表仍需要形成正式 Godot 可读导出流程；当前 V0.1/V0.2 使用少量测试数据验证系统闭环。
- V0.3 存档 schema 已提升到版本 5；当前原型不兼容缺少 V0.2/V0.3 动态字段的旧存档。
- 3D 大地图表现和模拟状态必须继续保持解耦，避免表现层直接修改业务状态。
- V0.2.1 城池坐标属于原型预览坐标，完整三国地图坐标和地形表达仍需后续专项从需求文档/数据母表落地。
- V0.3 只完成势力正统/名望底座，正式汉室状态表、官爵、诏令、称王称帝和复兴汉室路线仍待后续任务。
- V0.3 已完成城市士族支持和可配置压力入口，完整士族派系、请愿、出仕和地方事件链仍待后续任务。
- V0.3 已完成人物关系、忠诚和降将状态入口，完整叛逃、策反、封赏链和全武将关系网仍待后续任务。
- V0.3 已完成关隘/港口/水路规则入口，完整水战、舰船、港口清单、关隘坐标和独立战场仍待后续任务。
- V0.2 外交/谋略仅完成可校验入口，正式外交关系网、谋略成功率、反制、情报、事件联动仍待四份文档定位或后续专项确认。
- V0.2 AI 仅完成基础进攻目标筛选，完整战略 AI、外交 AI、都督府 AI、长期规划和多目标权衡仍待后续版本。
