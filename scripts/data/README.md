# 数据导入层

职责：

- 读取测试数据。
- 校验主键、必填字段、枚举和外键。
- 把静态主数据交给模拟层使用。
- 读取和校验 Content Alpha 阶段性内容索引，例如英雄半身像候选资源索引。
- 读取和校验 Content Alpha 候选资源包清单，避免来源项目、所有权状态、来源路径和允许用途只停留在文档说明。
- 后续工具和 UI 应通过统一 loader 读取 Content Alpha 资源清单，不直接绕过校验解析 JSON。
- 资源专用 loader 应从资源清单解析具体资源包，再加载对应索引，避免 UI 层硬编码数据文件路径。
- 阶段性内容验收应通过聚合校验入口串联清单、资源包、索引、预览行和真实资源解码，避免只验证单个文件存在。
- 英雄半身像导入清单必须校验项目内 PNG 的路径、大小、哈希、尺寸和英雄绑定，避免导入目录与审计索引脱节。
- 可复用半身像池只允许记录图片资源、尺寸、哈希和源英雄名参考，禁止泄漏源项目技能、传记、君略、数值、官职或势力等玩法字段。

禁止：

- 用默认值掩盖关键字段缺失。
- 静默跳过非法数据。
- 自动修正异常业务状态。
